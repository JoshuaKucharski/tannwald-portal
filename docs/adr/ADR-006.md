# ADR-006: Dateien privat, Auslieferung nur über geprüften Controller

**Status:** vorgeschlagen · **Datum:** 2026-11-01 · **Quelle:** Pflichtenheft §15 (`docs/pflichtenheft.md`)

## Kontext

PoC „myTannwald“ (Kundenportal der Tannwald Verpackungstechnik AG), Lastenheft `docs/lastenheft.yaml`,
Pflichtenheft `docs/pflichtenheft.md`.

## Entscheid

Dokumentdateien liegen im privaten Dateisystem (`private://dokumente/`) und werden nur über `/dokument/{nid}/download` ausgeliefert.

## Begründung

Kein direkter Dateipfad; Audit pro Download; produktiv SAS-URLs.
