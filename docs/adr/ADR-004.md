# ADR-004: drupal/ai als Provider-Abstraktion, Ollama lokal

**Status:** vorgeschlagen · **Datum:** 2026-11-01 · **Quelle:** Pflichtenheft §15 (`docs/pflichtenheft.md`)

## Kontext

PoC „myTannwald“ (Kundenportal der Tannwald Verpackungstechnik AG), Lastenheft `docs/lastenheft.yaml`,
Pflichtenheft `docs/pflichtenheft.md`.

## Entscheid

LLM- und Embedding-Aufrufe laufen über `drupal/ai`; lokal mit `ai_provider_ollama` (`qwen2.5:7b` für Chat, `bge-m3` für Embeddings).

## Begründung

Kein Lock-in, Wechsel per Konfiguration (NFA-QA-05), Datenschutz-Variante gratis.
