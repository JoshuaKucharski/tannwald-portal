# ADR-002: Node-Access-Grants plus eigener EntitlementService statt group-Modul

**Status:** vorgeschlagen · **Datum:** 2026-11-01 · **Quelle:** Pflichtenheft §15 (`docs/pflichtenheft.md`)

## Kontext

PoC „myTannwald“ (Kundenportal der Tannwald Verpackungstechnik AG), Lastenheft `docs/lastenheft.yaml`,
Pflichtenheft `docs/pflichtenheft.md`. Präzisierung D6a (2026-11-01): Search API ist im PoC nicht installiert; dieselben Realms filtern als `access_keys` den Chunk-Store.

## Entscheid

Sichtbarkeit entsteht aus Node-Access-Grants, deren Realms ein eigener `EntitlementService` (Modul `tannwald_access`) berechnet; das `group`-Modul wird nicht verwendet.

## Begründung

Rechte sind berechnet (Firma × Maschinentyp × Vertrag × Exportklasse), nicht Mitgliedschaften; Grants wirken automatisch in Views und Search API.
